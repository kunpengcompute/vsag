## v1.0.0

### Change Description

**New Features**

Provides an optimization patch based on vsag v1.0.0, implementing RaBitQ 4-bit table lookup, Computer object pooling and reuse in the preprocessing stage, BFS graph-order base vector reordering, and batch4 distance computation optimization for SQ8 and SQ8 Uniform.

None
